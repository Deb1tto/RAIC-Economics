### 1. 模块基础信息

*   **module_name**: 完全竞争与企业决策
*   **unit**: AP Micro Unit 3.6-3.7
*   **knowledge_point**: 利润最大化、停业规则与长期均衡
*   **learning_goal**: 学生将掌握完全竞争企业如何作为“价格接受者”通过 $MR=MC$ 实现利润最大化，理解比较价格与平均可变成本（$P$ vs $AVC$）的短期停业规则，并能通过并排图表（Side-by-side graphs）演示市场的长期进入和退出如何使经济利润归零，实现分配效率和生产效率。
*   **core_question**: 面对由市场决定的价格，竞争性企业如何决定产量乃至是否停业？市场的长期自动调整机制如何消除暴利与亏损？

**必须补充的说明**：
*   **这个知识点为什么值得单独做成一个模块**：完全竞争模型是微观经济学中所有市场结构的“黄金基准”。AP考试中最经典、分值最重的必考题型就是“画出完全竞争市场与企业的并排图（Side-by-side graphs），并展示从短期到长期的演变”。将静态的纸质图表做成两图联动的可视化应用，能让学生瞬间明白“市场交点如何平移成为企业的一根水平线”，以及“企业的进出如何反作用于市场供给”。
*   **这个模块最核心的教学目标是什么**：建立三套核心视觉与逻辑映射：(1) 价格接受者（$P=MR=AR=D$）；(2) 短期决策看两点（找 $MR=MC$ 定产量，看 $P$ 与 $ATC/AVC$ 定利润与停业）；(3) 长期均衡的终极回归（经济利润驱动企业进出，最终必定停在 $P = \text{minimum } ATC$）。
*   **它和整个平台其他模块的关系是什么**：本模块高度依赖 Unit 3.2 建立的短期成本曲线（$MC, ATC, AVC$）概念，同时作为基准模型，将与接下来的 Unit 4（垄断、垄断竞争、寡头）形成强烈的效率对比（完全竞争是唯一能在长期同时实现分配效率 $P=MC$ 和生产效率 $P=\text{min } ATC$ 的市场）。

### 2. 步骤区

**必须补充的说明**：
*   **为什么这个知识点要拆成这些步骤**：教学逻辑必须遵循“看懂当前状态 $\rightarrow$ 极端情况下的底线防守 $\rightarrow$ 时间拉长后的动态演变”这一路径。
*   **这些步骤的先后顺序为什么是这样**：必须先建立并排图表和利润最大化的基础（Step 1），然后再讨论当价格跌破成本时，企业在短期内是死扛还是关门（Step 2，即Unit 3.6的短期部分），最后再拔高到长期视角，看市场如何通过优胜劣汰恢复平静（Step 3，即Unit 3.6长期与3.7的结合）。
*   **每一步分别承担什么教学目标**：第一步解决“市场决定价格，企业接受价格赚取利润/亏损”的静态分析；第二步解决“短期停业点（Shut-down Point）”与“收支相抵点（Break-even Point）”的识别；第三步解决长期均衡（Long-run Equilibrium）的动态推导及双重效率的达成。
*   **学生在每一步应该重点理解什么**：第一步要理解企业的需求曲线是水平的；第二步要深刻理解“只要亏损小于固定成本，短期内就应该继续生产”的反直觉商业逻辑；第三步要理解“长期内没有人能一直赚取经济利润，只能赚取正常利润（Normal Profit）”。

#### 步骤 1：价格接受者与短期利润 (Unit 3.7)
*   **step_name**: 价格接受者与利润
*   **step_summary**: 探索市场供需如何决定价格，以及企业如何实现利润最大化。
*   **step_description**: 在完全竞争市场中，无数的买者和卖者使得单个企业成为价格接受者（Price Taker），面临一条完全弹性的水平需求曲线（$P=MR=AR=D$）。企业遵循 $MR=MC$ 规则确定产量，当价格高于平均总成本（$ATC$）时赚取经济利润。

#### 步骤 2：短期的生产与停业决策 (Unit 3.6)
*   **step_name**: 短期停业规则
*   **step_summary**: 价格下跌时，比较价格与平均可变成本，决定是否继续生产。
*   **step_description**: 短期内企业有固定成本的羁绊。如果价格跌破平均总成本（$ATC$）但高于平均可变成本（$AVC$），企业虽然亏损但应继续生产以分摊固定成本。只有当价格跌破最低 $AVC$（即停业点 Shut-down Price）时，企业才应立刻关门。

#### 步骤 3：长期均衡与效率 (Unit 3.6 / 3.7)
*   **step_name**: 长期均衡与效率
*   **step_summary**: 观察企业的进入和退出如何推动市场达到零经济利润的长期均衡。
*   **step_description**: 在长期中，所有生产要素均可变，企业可自由进出。经济利润会吸引新企业进入（市场供给增加，价格下降），经济亏损会导致企业退出（市场供给减少，价格上升）。最终市场稳定在 $P = \text{min } ATC$ 处，此时企业仅赚取正常利润，且同时实现分配效率和生产效率。

### 3. 操作区

#### 步骤 1：价格接受者与短期利润 (Unit 3.7)
*   **控制项 1：**
    *   **control_name**: 市场需求平移 (Market Demand)
    *   **control_type**: range
    *   **default_value**: 70 (偏高，使企业处于盈利状态)
*   **控制项 2：**
    *   **control_name**: 企业目标产量 (Firm's Quantity)
    *   **control_type**: range
    *   **default_value**: 50 (最优产量处)
*   **必须补充的说明**：
    *   **控制项 1** 作用于左侧的“市场图”。拖动滑块使市场需求曲线平移，以此改变市场均衡价格 $P_e$。
    *   **图表响应 1**：当市场需求平移导致左图的交点上下移动时，右侧“企业图”中的那条水平线（$P=MR=D$）必须像电梯一样，**被左侧的虚线牵引着同步上下移动**。这是建立“价格接受者”直觉的关键。
    *   **控制项 2** 作用于右侧的“企业图”。让学生试着偏离 $MR=MC$ 的最优产量，观察利润矩形面积的变化，验证“只有在 $MR=MC$ 处利润最大”。

#### 步骤 2：短期的生产与停业决策 (Unit 3.6)
*   **控制项 1：**
    *   **control_name**: 市场价格设定 (Market Price)
    *   **control_type**: range
    *   **default_value**: 40 (处于 ATC 与 AVC 之间)
*   **控制项 2：**
    *   **control_name**: 辅助计算透视
    *   **control_type**: select (选项：无 / 显示继续生产时的亏损 / 显示停业时的亏损)
    *   **default_value**: 显示继续生产时的亏损
*   **必须补充的说明**：
    *   在此步骤中，右图（企业图）额外增加一条 $AVC$ 曲线。
    *   滑块向下拖动价格水平线，依次穿过“收支相抵点（Break-even Point, 最低ATC）”和“停业点（Shut-down Point, 最低AVC）”。
    *   **图表响应与辅助文案**：当价格处于 $ATC$ 和 $AVC$ 之间时，UI 亮起黄灯警告“经济亏损，但应继续营业 (Loss minimizing)”；当价格低于最低 $AVC$ 时，UI 亮起红灯并弹出“跌破停业点，立刻关门！(Shut down)”。切换透视选项时，图表用红色面积高亮显示亏损区域（继续生产的亏损是 $ATC$ 和 $P$ 之间的矩形；停业的亏损是总固定成本 $TFC$，即 $ATC$ 和 $AVC$ 之间的整个大矩形）。

#### 步骤 3：长期均衡与效率 (Unit 3.6 / 3.7)
*   **控制项 1：**
    *   **control_name**: 市场初始状态
    *   **control_type**: select (选项：行业存在经济利润 / 行业存在经济亏损 / 长期均衡)
    *   **default_value**: 行业存在经济利润
*   **控制项 2：**
    *   **control_name**: 长期时间推移 (Long-run Adjustment)
    *   **control_type**: range
    *   **default_value**: 0
*   **必须补充的说明**：
    *   这是动态演示“看不见的手”如何运作。
    *   **图表响应**：选择“行业存在经济利润”时，左侧市场图交点较高，右侧企业图的水平线高于 $ATC$。此时激活“长期时间推移”滑块。
    *   向右拖动滑块时，UI 浮现无数小工厂飞入画面的动画（代表企业进入）。同时，**左侧市场图的供给曲线 ($S$) 自动向右缓慢平移**。随着 $S$ 向右，市场价格开始下降。这带动右侧企业图的水平价格线逐渐下降，原有的绿色“经济利润矩形”被不断压缩。当滑块拖到最右端（长期），市场供给曲线停止移动，此时价格线刚好切在右图企业 $ATC$ 曲线的最底端。UI 弹出“零经济利润（正常利润），实现长期均衡！”横幅。

### 4. 图表区

#### 步骤 1：价格接受者与短期利润 (Unit 3.7)
*   **chart_title**: 市场与企业的并排模型 (Side-by-side Graphs)
*   **chart_subtitle**: 观察市场决定的价格如何成为企业的需求线，并在 MR=MC 处找利润
*   **x_axis_label**: (左图) 市场总量 (Market Q) / (右图) 企业产量 (Firm q)
*   **y_axis_label**: (左右共用) 价格与成本 (Price/Cost)
*   **必须补充的说明**：
    *   **最希望看到的现象**：左边宏大的市场交点，决定了右边微小个体命运的基准线；企业唯一能做的就是在自己的成本曲线里寻找最佳产量。
    *   **关键对象绘制**：并排两张图。左图：大写的 $S$ 和 $D$ 曲线，交于 $(Q_M, P_e)$。右图：U型的 $MC$ 和 $ATC$ 曲线。一条水平的虚线从左图的 $P_e$ 横跨到右图，标记为 $P=MR=AR=D$。
    *   右图包含一个可移动的产量点 $q$。当 $q$ 处于 $MR=MC$ 时，自动渲染一个高亮的矩形：宽为 $0$ 到 $q$，高为 $P_e$ 到对应产量的 $ATC$。填充绿色表示 Profit。

#### 步骤 2：短期的生产与停业决策 (Unit 3.6)
*   **chart_title**: 企业的短期亏损与停业点 (Shut-down Point)
*   **chart_subtitle**: 下调价格，比较停业亏损与继续生产的亏损
*   **x_axis_label**: 企业产量 (Firm q)
*   **y_axis_label**: 价格与成本 (Price/Cost)
*   **必须补充的说明**：
    *   **最希望看到的现象**：固定成本是已经泼出去的水（Sunk cost）。只要卖出的价格还能抵消掉可变成本（工人工资、材料），就应该咬牙坚持。
    *   **关键对象绘制**：只需右侧企业图（放大）。包含 U 型的 $MC$, $ATC$, $AVC$。
    *   两条至关重要的隐藏辅助准星：最低 $ATC$ 点（标出虚线，写明“收支相抵点”），最低 $AVC$ 且与 $MC$ 相交的点（标出虚线，写明“短期停业点”）。亏损的红色面积根据控制项2的选项进行不同逻辑的面积填充计算。

#### 步骤 3：长期均衡与效率 (Unit 3.6 / 3.7)
*   **chart_title**: 从短期失衡到长期均衡 (Long-run Adjustment)
*   **chart_subtitle**: 企业的进出改变市场供给，直到经济利润被完全抹平
*   **x_axis_label**: (左图) 市场总量 (Market Q) / (右图) 企业产量 (Firm q)
*   **y_axis_label**: (左右共用) 价格与成本 (Price/Cost)
*   **必须补充的说明**：
    *   **最希望看到的现象**：右侧企业利润的存在会引来左侧市场图供给线的位移，这是一个闭环的动态系统。最终落脚点完美符合微观经济学的双重效率。
    *   **关键对象绘制**：恢复并排双图。左侧保留初始供给线 $S_1$ 作为影子虚线，绘制移动中的新供给线 $S_2$。右侧水平线联动上下平移。
    *   当达到长期均衡时（$P=\text{min } ATC$），在右图该点向外发射强烈的引导线，标记两行大字：“分配效率 Allocative Efficiency ($P=MC$)”与“生产效率 Productive Efficiency ($P=\text{min } ATC$)”。

### 5. 数据项

#### 步骤 1：价格接受者与短期利润 (Unit 3.7)
*   **metric_name**: 市场均衡价格 ($P_e$), 企业最优产量 ($q^*$), 平均总成本 ($ATC$), 总经济利润 (Total Profit)
*   **必须补充的说明**：
    *   企业最优产量 $q^*$ 为 $MR=MC$ 交点处的横坐标。总利润公式为 $(P_e - ATC) \times q^*$。
    *   **Hover交互**：悬停“总经济利润”时，右侧图表中的绿色利润矩形进行呼吸闪烁，左侧市场图中对应的一小段供给曲线加粗（暗示市场中无数个这样的企业构成了整个供给）。

#### 步骤 2：短期的生产与停业决策 (Unit 3.6)
*   **metric_name**: 市场价格 ($P$), 平均可变成本 ($AVC$), 停业亏损 (Loss if shut down), 继续营业亏损 (Loss if producing)
*   **必须补充的说明**：
    *   “停业亏损”即总固定成本 $TFC = (ATC - AVC) \times q$。“继续营业亏损”$= (ATC - P) \times q$。
    *   这两个数据的并排展示直击考试痛点。当价格在 $ATC$ 与 $AVC$ 之间时，系统用绿色字体高亮“继续营业亏损”（因为它数值更小，是更优选）；当价格低于 $AVC$ 时，用绿色字体高亮“停业亏损”。
    *   **Hover交互**：悬停这俩数据项时，图表切换并高亮对应的几何矩形面积，帮助学生理解为何要“两害相权取其轻”。

#### 步骤 3：长期均衡与效率 (Unit 3.6 / 3.7)
*   **metric_name**: 行业企业数量趋势, 市场总产量 ($Q_M$), 单个企业产量 ($q$), 企业经济利润
*   **必须补充的说明**：
    *   “行业企业数量趋势”为方向性文本：“正有企业涌入 (Firms Entering)”、“正有企业退出 (Firms Exiting)”、“停止进出 (No Entry/Exit)”。
    *   **深度数据联动**：学生会发现，在企业涌入的过程中，虽然“市场总产量”在增加，但由于价格被压低，“单个企业产量”其实在沿着 MC 曲线向左下方回落（变小）。这个反直觉的考点必须通过这两个数据的对比来呈现。
    *   **Hover交互**：悬停在归零的“企业经济利润”上时，右图弹出标注：“注意：经济利润为零意味着企业正在赚取正常的会计利润（Normal Profit），企业家的机会成本已得到补偿！”。
