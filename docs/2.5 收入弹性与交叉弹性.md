根据《模块产品文档要求》以及AP微观经济学考纲（Unit 2.5 Other Elasticities），以下为您整理的“其他弹性：交叉价格弹性与收入弹性”模块产品需求文档。

### 1. 模块基础信息

*   **module_name**: 交叉价格与收入弹性
*   **unit**: AP Micro Unit 2.5
*   **knowledge_point**: 交叉价格弹性、收入弹性
*   **learning_goal**: 学生将掌握如何计算和解释收入弹性（YED）与交叉价格弹性（XED），通过弹性系数的正负号准确判断商品性质（正常品/劣质品，替代品/互补品），并直观理解这些外部因素变动如何导致需求曲线的平移。
*   **core_question**: 消费者的收入变化或其他相关商品的价格变化，会如何定量地影响某种特定商品的需求？

**必须补充的说明：**
*   **为什么单做这个模块**：在Unit 2.1中学生已经定性地学过非价格因素（如收入和相关商品价格）如何导致需求曲线移动，在Unit 2.3中学过了利用自身价格弹性（PED）进行定量计算。Unit 2.5是将定性与定量结合，用具体的“弹性系数正负号”来精确描述曲线平移的方向。初学者极易混淆公式的分母以及死记硬背正负号含义。通过交互式的滑块和可视化关联，可以让抽象的代数公式与几何图形的左右移动产生直观绑定。
*   **最核心的教学目标**：建立起“弹性系数的正负号决定了曲线平移方向”的绝对直觉。让学生深刻理解：YED > 0 代表同向变化（正常品），YED < 0 代表反向变化（劣质品）；XED > 0 代表同向变化（替代品），XED < 0 代表反向变化（互补品）。
*   **与平台其他模块关系**：该模块是供需模型与弹性分析的直接进阶，同时也会在宏观经济学中（如汇率变动对外贸的交叉影响）提供底层思维模型支撑。

### 2. 步骤区

**必须补充的说明：**
*   **为什么这个知识点要拆成这些步骤**：教材中“Other Elasticities”明确包含了两种不同维度的自变量：消费者自身的收入（Income）和外部其他商品的价格（Price of related goods）。这两种弹性的计算公式虽然极为相似（分子都是需求量百分比变动，仅仅分母不同），但经济学含义和应用场景完全不同，必须拆开独立讲解，避免自变量混淆。
*   **先后顺序逻辑**：先分析单一市场下消费者自身属性的收入效应（Step 1），再扩展到两个不同市场、两种商品之间的交叉价格效应（Step 2）。从单主体到跨市场，认知负荷逐步递增。
*   **每一步承担的教学目标与重点**：第一步解决“商品是好是坏”的判定，重点理解正号=正常品、负号=劣质品；第二步解决“商品之间的关联关系”，重点理解正号=替代品、负号=互补品。

#### 步骤 1：收入弹性与商品属性 (YED)
*   **step_name**: 收入弹性分析
*   **step_summary**: 调整消费者收入，观察正常品与劣质品需求曲线的移动方向。
*   **step_description**: 收入弹性衡量一种商品的需求量对消费者收入变动的反应程度。当弹性系数为正时，该商品为正常品（收入越多买得越多）；当系数为负时，该商品为劣等品（收入越多买得越少）。

#### 步骤 2：交叉价格弹性 (XED)
*   **step_name**: 交叉价格弹性
*   **step_summary**: 改变商品B的价格，观察对商品A需求曲线的影响及弹性系数。
*   **step_description**: 交叉价格弹性衡量商品A的需求量对商品B价格变动的反应程度。系数为正代表两者是替代品（B涨价导致A销量增加），系数为负代表两者是互补品（B涨价导致A销量减少）。

### 3. 操作区

#### 步骤 1：收入弹性与商品属性 (YED)
*   **控制项 1：**
    *   **control_name**: 商品性质 (Good Type)
    *   **control_type**: select (选项：正常品 Normal Good / 劣质品 Inferior Good)
    *   **default_value**: 正常品
*   **控制项 2：**
    *   **control_name**: 消费者收入变动 (%Δ Income)
    *   **control_type**: range (取值范围：-50% 到 +50%，步长10%)
    *   **default_value**: 0
*   **必须补充的说明**：
    *   这两个控制项用于设定基础前提（商品是好是坏）并施加外部冲击（收入增减）。
    *   **图表响应逻辑**：拖动“消费者收入变动”滑块时，图表上的需求曲线会发生平移。如果选择“正常品”，向右拖动收入滑块（收入增加），需求曲线向右平移；如果选择“劣质品”，向右拖动收入滑块，需求曲线反而向左平移。
    *   **辅助提示**：当曲线发生移动时，UI界面中心弹出高亮的动态标签：“YED > 0 (正常品)” 或 “YED < 0 (劣质品)”。

#### 步骤 2：交叉价格弹性 (XED)
*   **控制项 1：**
    *   **control_name**: 商品A与B的关系
    *   **control_type**: select (选项：替代品 Substitutes / 互补品 Complements)
    *   **default_value**: 替代品
*   **控制项 2：**
    *   **control_name**: 市场B价格变动 (%Δ Price of B)
    *   **control_type**: range (取值范围：-50% 到 +50%，步长10%)
    *   **default_value**: 0
*   **必须补充的说明**：
    *   这组控件用于展示跨市场的联动效应。
    *   **图表响应逻辑**：如果关系选择为“替代品”，当“市场B价格”向右拖动（B涨价）时，主图表（市场A）的需求曲线向右平移（A销量增加）。如果关系为“互补品”，当B涨价时，A的需求曲线向左平移。
    *   **辅助文案**：在操作区旁醒目展示数学演算过程：`XED = %ΔQ_A / %ΔP_B`。当滑块拖动时，实时将正负数值代入公式，自动计算出正负结果，强化代数运算的肌肉记忆。

### 4. 图表区

#### 步骤 1：收入弹性与商品属性 (YED)
*   **chart_title**: 收入变动与需求平移 (YED)
*   **chart_subtitle**: 设定商品性质并调整收入，观察需求曲线的位移方向
*   **x_axis_label**: 需求量 (Quantity, Q)
*   **y_axis_label**: 价格 (Price, P)
*   **必须补充的说明**：
    *   **最希望看到的现象**：明确“收入增加不等于需求绝对增加”，必须先看商品性质的正负号逻辑。
    *   **关键对象绘制**：固定一条浅灰色的初始需求曲线 $D_1$，随着操作生成一条高亮的移动后需求曲线 $D_2$。在图表中设定一条固定的水平价格基准线 $P_e$，标出初始数量 $Q_1$ 和新数量 $Q_2$。在 $Q_1$ 和 $Q_2$ 之间绘制一个带有百分比数值（`%ΔQ`）的动态粗箭头（向右或向左），将数量的百分比变动具象化。

#### 步骤 2：交叉价格弹性 (XED)
*   **chart_title**: 市场B价格波动对商品A需求的影响
*   **chart_subtitle**: 观察替代品与互补品在面临关联市场价格变动时的不同反应
*   **x_axis_label**: 商品A的需求量 (Quantity of A)
*   **y_axis_label**: 商品A的价格 (Price of A)
*   **必须补充的说明**：
    *   **最希望看到的现象**：深刻理解“交叉联动效应”——B涨价，A反而卖得更好（替代关系）；B涨价，A卖得更差（互补关系）。
    *   **关键对象绘制**：主图依然是展示 $D_1$ 和 $D_2$ 曲线平移（同Step 1）。**核心差异点在于**：建议在图表右上角或左侧开一个**“画中画 (Mini-chart)”**代表市场B。画中画里只有一个纵轴（Price of B）和一个代表价格的圆点。当用户拖动Step 2的操作滑块时，画中画里的价格点上下移动，与此同时，主图里的需求曲线随之左右平移。这种视觉关联能完美解释“Cross (交叉)”的物理意义。

### 5. 数据项

#### 步骤 1：收入弹性与商品属性 (YED)
*   **metric_name**: 收入变动百分比 (%Δ Income), 需求量变动百分比 (%Δ Quantity), 收入弹性系数 (YED), 商品属性判定
*   **必须补充的说明**：
    *   弹性系数由公式 `YED = %Δ Quantity / %Δ Income` 实时计算。
    *   “商品属性判定”根据 YED 结果自动输出文本：“正常品 (Normal Good)” 或 “劣质品 (Inferior Good)”。
    *   **Hover交互**：当鼠标悬停在“收入弹性系数 (YED)”数值或公式时，图表中代表数量变化的水平粗箭头高亮（对应分子），操作区的收入滑块刻度同时高亮闪烁（对应分母），帮助学生从视觉上重构除法公式的意义。

#### 步骤 2：交叉价格弹性 (XED)
*   **metric_name**: 市场B价格变动 (%Δ P_B), 商品A需求量变动 (%Δ Q_A), 交叉价格弹性系数 (XED), 关联关系判定
*   **必须补充的说明**：
    *   弹性系数由公式 `XED = %Δ Q_A / %Δ P_B` 实时计算。
    *   “关联关系判定”输出文本：“替代品 (Substitutes)” 或 “互补品 (Complements)”。
    *   **Hover交互**：当鼠标悬停在“关联关系判定”结果上时，若判定为替代品，则画中画里向上的价格箭头和主图里向右的需求箭头同时闪烁绿色；若为互补品，则画中画里的向上价格箭头与主图里向左的需求萎缩箭头（一红一绿）交替闪烁，通过同向/反向的箭头动画，视觉强化 Substitute 与 Complement 的核心差异。
