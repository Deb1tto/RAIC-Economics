### 1. 模块基础信息

*   **module_name**: 利润类型与利润最大化规则
*   **unit**: AP Micro Unit 3.4-3.5
*   **knowledge_point**: 经济/会计利润与 MR=MC 规则
*   **learning_goal**: 学生将明确区分会计利润和经济利润，理解隐性成本（机会成本）在企业决策中的决定性作用，并牢牢掌握微观经济学中企业行为的终极黄金法则——边际收益等于边际成本（MR=MC）即为利润最大化点。
*   **core_question**: 什么是真正的“赚钱”（正常利润 vs 经济利润）？企业到底应该生产多少数量才能让总利润达到最大？

**必须补充的说明：**
*   **这个知识点为什么值得单独做成一个模块**：在日常认知中，学生只知道“收入减去成本等于利润（会计利润）”。在AP微观经济学中，必须强行植入“隐性成本（Implicit Costs）”和“正常利润（Normal Profit）”的防杠概念。此外，寻找利润最大化产量是后续所有市场结构（完全竞争、垄断、寡头等）解题的绝对起手式，也是贯穿 Unit 3 到 Unit 4 的核心钥匙。
*   **这个模块最核心的教学目标是什么**：第一，建立等式直觉：经济利润 = 总收入 - 显性成本 - 隐性成本。第二，建立几何与代数直觉：总利润（TR-TC）的垂直距离最大的地方，必然是边际收益（MR）和边际成本（MC）曲线相交的地方。
*   **它和整个平台其他模块的关系是什么**：它是 Unit 1.5-1.6 成本收益分析（MB=MC）在企业生产行为中的具体具象化。同时，本模块打造的 MR=MC 决策组件，将直接原封不动地被 Unit 3.7（完全竞争）、Unit 4.2（垄断）等模块作为判定产量的第一步复用。

### 2. 步骤区

**必须补充的说明：**
*   **为什么这个知识点要拆成这些步骤**：教学逻辑必须遵循“重新定义利润（概念清理） $\rightarrow$ 寻找利润最大化的总量视角（直观面积） $\rightarrow$ 寻找利润最大化的边际视角（核心解题工具）”的顺序。
*   **这些步骤的先后顺序为什么是这样**：Step 1 先把“什么是利润”说清楚（区别会计与经济利润，引入正常利润）；在知道了利润怎么算之后，Step 2 从宏观上看总收入和总成本的差距；Step 3 再下钻到微观层面，用边际（每多生产一个）的视角来推导 MR=MC 原则。
*   **每一步分别承担什么教学目标**：第一步解决“经济利润为 0 时企业为什么还不关门（因为赚到了正常利润）”的必考错题；第二步解决利润总额的最大化直觉；第三步解决 AP 最爱考的 “如果 MR>MC 该怎么办？如果 MR<MC 该怎么办？” 的动态决策过程。
*   **学生在每一步应该重点理解什么**：第一步理解隐性成本是放弃的其他机会带来的损失；第二步理解最大的总收入不等于最大的总利润；第三步理解只要多生产一个带来的钱（MR）大于成本（MC）就该继续生产，直到两者相等为止。

#### 步骤 1：会计利润与经济利润 (Unit 3.4)
*   **step_name**: 会计与经济利润
*   **step_summary**: 引入隐性成本，区分会计利润与经济利润及正常利润。
*   **step_description**: 会计利润只扣除了实际支付的显性成本。而经济利润还必须扣除企业家放弃的其他机会所带来的隐性成本（如放弃的工资）。当经济利润正好为零时，企业赚得“正常利润（Normal Profit）”，这足以让企业继续经营。

#### 步骤 2：总收益与总成本视角 (Unit 3.5)
*   **step_name**: 总量视角的利润
*   **step_summary**: 通过对比总收益 (TR) 和总成本 (TC) 曲线，寻找最大利润空间。
*   **step_description**: 企业的总利润等于总收益减去总经济成本。通过观察随着产量的增加，TR 曲线和 TC 曲线之间的垂直距离如何变化，我们可以直观地找到那个让总利润（两线间距）达到最大的黄金产量点。

#### 步骤 3：MR = MC 利润最大化规则 (Unit 3.5)
*   **step_name**: MR=MC 黄金法则
*   **step_summary**: 利用边际分析，证明边际收益等于边际成本时利润最大。
*   **step_description**: 理性的企业会通过比较边际收益（MR）和边际成本（MC）来决定产量。只要 MR > MC，增加产量就会增加总利润；当 MR < MC，增加产量反而会减少利润。因此，利润最大化的条件永远是 MR = MC。

### 4. 图表区

#### 步骤 1：会计利润与经济利润 (Unit 3.4)
*   **chart_title**: 两种利润计算视角的对比
*   **chart_subtitle**: 调整收入与成本，观察经济利润何时为零（获得正常利润）
*   **x_axis_label**: 账本视角 (Accounting vs. Economic)
*   **y_axis_label**: 金额 (Dollars)
*   **必须补充的说明**：
    *   **核心现象**：经济学家眼里的成本总是比会计师眼里的成本更高，因此经济利润总是小于会计利润。
    *   **关键对象**：这是一组 **动态堆叠柱状图 (Stacked Bar Chart)**。
        *   左柱：单根大柱子，代表总收入 (Total Revenue)。
        *   中柱（会计视角）：分为上下两截，下方是“显性成本”，上方是“会计利润”。
        *   右柱（经济视角）：分为三截，最下方是“显性成本”，中间是“隐性成本”，最上方是“经济利润”。如果总收入太低，导致右柱加起来高度不够，则顶部出现倒挂的红色虚线框标注为“经济亏损 (Economic Loss)”。

#### 步骤 2：总收益与总成本视角 (Unit 3.5)
*   **chart_title**: 总利润最大化的几何位置
*   **chart_subtitle**: 拖动产量游标，寻找总收入与总成本垂直距离最大的点
*   **x_axis_label**: 生产数量 (Quantity, Q)
*   **y_axis_label**: 总金额 (Total Dollars)
*   **必须补充的说明**：
    *   **核心现象**：利润最大化发生在 TR 曲线高于 TC 曲线且两者差距最大的地方。
    *   **关键对象**：一条从原点出发的向上倾斜的直线作为总收益 (TR)；一条从正 Y 轴（固定成本）出发的呈反S型的总成本 (TC) 曲线。核心是两根线之间的**垂直距离线段**，该线段需加粗并在旁边悬浮显示当前的“总利润 = $xx”标签。

#### 步骤 3：MR = MC 利润最大化规则 (Unit 3.5)
*   **chart_title**: 边际收益与边际成本决策 (MR=MC Rule)
*   **chart_subtitle**: 观察为什么只有在 MR 与 MC 相交的点，企业才停止调整产量
*   **x_axis_label**: 生产数量 (Quantity, Q)
*   **y_axis_label**: 边际金额 (Marginal Dollars)
*   **必须补充的说明**：
    *   **核心现象**：寻找利润最大化就是寻找交点。在交点左边，赚的比花的多；在交点右边，花的比赚的多。
    *   **关键对象**：建立二维坐标系。画一条水平直线代表边际收益（MR=P），画一条标准的 U 型边际成本（MC）曲线。交点 $Q^*$ 用金色五角星或高亮圆点标记。
    *   **面积联动**：从 Y 轴到当前产量 Q 的垂直线之间，MR 与 MC 之间的面积即为“总利润的增量”。当 Q 从 0 向交点移动时，这块绿色面积不断扩大；一旦越过交点，超出的部分在 MC 和 MR 之间用红色阴影填充，表示“利润的倒扣（损失）”。

### 5. 数据项

#### 步骤 1：会计利润与经济利润 (Unit 3.4)
*   **metric_name**: 会计利润 (Accounting Profit), 经济利润 (Economic Profit), 企业经营状态判定
*   **必须补充的说明**：
    *   计算逻辑：会计利润 = TR - 显性成本；经济利润 = 会计利润 - 隐性成本。
    *   企业经营状态判定：根据经济利润的值输出：“获利丰厚 (Economic Profit > 0)” / “赚取正常利润 (Normal Profit, = 0)” / “经济亏损 (Economic Loss < 0)”。
    *   **Hover交互**：当鼠标悬停在“正常利润”字段时，图表右侧经济视角柱子中的“隐性成本”色块高亮闪烁，并在旁边浮现文字框“虽然没赚到超额利润，但你的时间和资本得到了应有的补偿（覆盖了机会成本）”，直击核心痛点。

#### 步骤 2：总收益与总成本视角 (Unit 3.5)
*   **metric_name**: 当前总收益 (TR), 当前总成本 (TC), 当前总利润 (Total Profit)
*   **必须补充的说明**：
    *   直接读取图中坐标或代入函数计算。当前总利润 = TR - TC。
    *   **Hover交互**：悬停“当前总利润”时，图表中对应的 TR 和 TC 之间的绿色（或红色）垂直距离线段会产生剧烈的呼吸闪烁。

#### 步骤 3：MR = MC 利润最大化规则 (Unit 3.5)
*   **metric_name**: 边际收益 (MR), 边际成本 (MC), 边际利润 (Marginal Profit), 行动建议 (Action)
*   **必须补充的说明**：
    *   边际利润 = MR - MC。
    *   行动建议输出文本：“增加产量 (Increase Q)” / “保持不变 (Profit Maximized)” / “减少产量 (Decrease Q)”。
    *   **Hover交互**：当学生选错产量（如在 MR<MC 的区间）并悬浮“边际利润（此时为负数）”时，图表中对应的红色“利润倒扣”阴影三角形会高亮并打上一个巨大的红色“X”，警告学生“这部分生产正在蚕食你之前赚到的利润”。帮助学生在视觉上彻底绑定 MR=MC 的代数判定。
